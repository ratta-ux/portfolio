# Personal Portfolio

This is my personal portfolio website showcasing my work and experience in UX/UI design and development.

## Project Structure

```
.
├── index.html              # Home page
├── pages/                  # All other pages
│   ├── about-page.html    # About me page
│   ├── blog-page.html     # Blog posts
│   ├── custom-404.html    # Custom 404 error page
│   └── case-studies/      # Case study pages
│       ├── aia-case-study.html
│       ├── makro-case-study.html
│       └── vocab-go-case-study.html
├── assets/                # Static assets
│   ├── css/              # Stylesheets
│   ├── js/               # JavaScript files
│   └── images/           # Image assets
└── .github/              # GitHub specific files
    └── workflows/        # GitHub Actions workflows
```

## Development

This project is a static website built with HTML, CSS, and JavaScript. It's deployed using GitHub Pages.

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch or the feature/update-homepage branch.

Visit the live site at: https://[your-username].github.io/portfolio/
