Understanding the problem

The existing design exhibited inefficiencies, particularly in navigation. Users frequently encountered difficulties such as extensive scrolling to locate desired content, occasional navigation stalls requiring restarting from the beginning, and an overall challenging experience in finding information.

The existing flow created significant friction in the user journey, leading to frustration and abandoned purchases.

Before redesigning, I led a workshop and collaborated with product managers, developers, and business analysts to identify business and tech constraints and user pain points to build our roadmap. I also interviewed the operations team since the design changes would directly affect their work routines.

Search Issues

Difficult to find product via search

Users struggle to find products using the search function, often requiring 5-6 tries.

Navigation

Categories are ambiguous

Hard to scroll to find products due to unclear category organization.

UX Issues

Difficult to navigate

Hard to navigate between screens with no way to return to previous views.

Checkout

Navigation limited

Too many steps in checkout causing user abandonment.

"

The search function is still difficult... Sometimes I spend 5 or 6 tries to find the right product.

— A Retail User, Bangkok

03/

The Solution

Here is the design solution that addresses the key pain points identified during research:

New homepage, new product category layout

Redesigned the homepage with intuitive categorization and visual cues for easy navigation.

Optimized category accessibility

Clear visual hierarchy and improved category labels reduce cognitive load.

Enhanced search accuracy

Implemented predictive search with spelling correction and search history.

Enable smooth navigation back

Consistent back buttons and breadcrumb navigation for clear user orientation.

Streamlined checkout

Reduced steps and improved flow in the checkout process to decrease abandonment.

Error prevention

Implemented forgiving search with spelling correction and helpful suggestions.

What I Learn

Key insights and takeaways from this project

01

Communication is key

It serves as a preventive measure against issues and helps identify any blocks the team may face. Regular and clear communication across teams was critical to the project's success.

02

Break down complexity

Simplification is crucial, as users should not have to ponder when shopping. Focus on solving key pain points first and create intuitive paths for users.

03

Open to feedback

Listen from different perspectives while advocating for users' needs. Diverse input from stakeholders leads to more robust solutions and better alignment.
